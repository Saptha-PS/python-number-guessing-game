# python-number-guessing-game
A beginner python game where the user tries to guess a randomly generated number within limited number of attempts.
## About the project
This is a simple number guessing game created using python.
The computer randomly selects a number between 1 to 1000,and the user has limited number of attempts to guess it.
After each guess,the program tells the user whether the guess is too high or too low and shows how many attempts are remaining.

## How the game works
1.The computer randomly selects a number between 1 to 1000.
2.The user enters a guess.
3.The program checks the guess.
4.The program tells the user whether the guess is too high or too low.
5.The number of remaining attempts is displayed.
6.The game ends when the user correctly guesses the number or runs out of attempts.
